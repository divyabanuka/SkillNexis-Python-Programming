## 📝 Assignments

### 1. 🌡️ Temperature Converter

Converts temperatures between Celsius and Fahrenheit using Python functions.

**File:** `Assignments/Assignment-1-Temperature-Converter/temperature_converter.py`

### 2. 🎓 Student Grade Calculator

Accepts student marks, calculates the average, and assigns a grade based on the average.

**File:** `Assignments/Assignment-2-Student-Grade-Calculator/student_grade_calculator.py`

### 3. 🔢 Even/Odd & Prime Number Checker

Checks whether a number is even or odd and determines whether it is a prime number.

**File:** `Assignments/Assignment-3-Even-Odd-Prime/number_checker.py`

---

## 🏧 Mini Project — Simple ATM Simulator

A simple console-based ATM simulator developed using Python.

### Features

- 🔐 PIN-based login
- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- ⚠️ Insufficient balance validation
- 🚪 Exit option
- 🔄 Menu-driven program
- 🧩 Functions for different ATM operations

**File:** `Mini-Project/Simple-ATM-Simulator/atm_simulator.py`
